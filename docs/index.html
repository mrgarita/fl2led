蛍光灯と電球を LED に替える前に知っておくこと

自宅にある電球（通常サイズ・ミニ）、丸形蛍光灯、直管蛍光灯（棒状の蛍光灯）を LED に替えるために、交換するときの注意点、LED にするメリット・デメリット、LED の基礎知識を調べてまとめました。

2026年11月13日時点の情報です。事実には出典の番号を付け、推測には「（推測）」と書いています。

まず押さえておきたい 3 つのこと

1. 蛍光ランプは作られなくなっていく（今あるものは使い続けてよい）

水銀に関する水俣条約にもとづき、日本でも一般照明用の蛍光ランプは種類ごとに製造と輸出入が禁止されます。電球形は 2026年1月1日から（30W を超えるものは 2027年1月1日から）、直管形と環形（丸形）は 2028年1月1日からです。直管形・環形のうち、ハロりん酸塩を主成分とする蛍光体を使ったものは 2027年1月1日からです[1]。

つまり、今ある蛍光灯がすぐに使えなくなるわけではありません。ただ、国内メーカーは蛍光ランプ用の照明器具の製造販売をすでに終えています[2]。替えのランプも、在庫が減るにつれて手に入りにくく、選びにくくなっていくと考えられます（推測）。

2. 蛍光灯は「器具ごと交換」が基本

蛍光灯を LED にする方法は、照明器具ごと交換する方法と、器具はそのままで蛍光ランプを LED ランプに替える方法の 2 つです[2]。後者は器具とランプの組み合わせを間違えると発煙・発火につながり、実際に火災の事故が起きています[2]。日本照明工業会とメーカーは、古い器具はランプだけでなく器具ごと LED 照明に交換することを勧めています[3][4]。

3. 電球は「口金・明るさ・光の色・器具の条件」を合わせれば差し替えられる

電球形 LED ランプは、今の器具の口金と同じなら取り付けられます。ただし、調光機能の付いた器具、密閉形の器具、センサー付きの器具、断熱材施工の器具などでは、対応した製品でないと使えません[5]。

3 系統ごとの替え方（早見表）

棒状の蛍光灯		 器具ごと LED 器具に替える 多くは電気工事

「多くは電気工事」は、住宅の直管蛍光灯器具は配線に直接つながっているものが多いという見立てです（推測）。自宅の器具が配線器具に差し込むタイプかどうかで変わります。
