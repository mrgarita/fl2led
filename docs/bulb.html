電球（通常サイズ・ミニ）を LED にする

電球は、器具はそのままで LED 電球に差し替えられます。今の器具の口金と同じなら取り付けられますが、器具によっては対応した製品が必要です[1]。

自宅の 2 種類の電球

通常サイズの電球は一般電球で、口金は E26 です。ミニの電球は小形電球（クリプトン電球）で、口金は E17 です[1]。口金のサイズは、口金の直径を定規で測ると確かめられます[2]。E の後ろの数字がおおよその直径（mm）です。

選ぶときの 6 つのポイント

1. 口金

器具の取り付け口に合うサイズを選びます。家庭用では E26（メインの照明など）と E17（ダウンライト・間接照明など）が中心で、ほかに E12・E11 もあります[2]。

2. 明るさ（lm：ルーメン）

LED 電球の明るさは、ワット数ではなく全光束（lm）で表します。今の電球と同じ「○○形相当」の表示を選ぶと、同じくらいの明るさになります[1][2]。

同じ「60形」でも、一般電球（810 lm）と小形電球（760 lm）で基準の値が違います。冊子にはこのほか 150形・200形の一般電球と、ボール電球の表もあります[1]。

3. 光の色

日の出・日の入りの太陽や白熱電球のような、オレンジがかった落ち着いた光が電球色です。正午の太陽や蛍光ランプに多い、白が際立つさわやかな光が昼白色・昼光色です[1]。その中間の温白色などを用意している製品もあります[2]。色の数値（K：ケルビン）や、色の見え方を表す演色性（Ra）は基礎知識にまとめました。

4. 光の広がり（配光）

LED 電球には、光が空間全体に広がる全般配光形（配光角 180° 以上）と、主に下方向を照らす準全般配光形（90° 以上 180° 未満）などがあります。準全般配光形をペンダントやシャンデリアに使うと、シェードの上側が暗くなることがあります[1]。

5. 器具の条件（いちばん大事）

次のような器具に、対応していない LED 電球を使うと、寿命が短くなったり、ちらつき・不点灯・破損・発煙の原因になったりします[1]。器具の表示と、LED 電球のパッケージの「○○対応」の表示を照らし合わせます。

器具の種類見分け方選ぶ LED 電球
密閉形器具浴室灯・玄関灯など、電球がカバーで覆われていて熱がこもる[2][3]密閉形器具対応
断熱材施工器具天井の断熱材の中に埋め込むダウンライトなど。器具に SB・SGⅠ・SG の表示がある[1][2]断熱材施工器具対応（非対応品は放熱が妨げられ、短寿命や火事の原因になる[2]）
調光機能付き明るさを変えられるつまみ・スライダー（調光器）がある[1]調光器対応（非対応品は破損・発煙の原因[1]）
センサー・遅れスイッチ付き人感センサー・明るさセンサーで自動点灯する、消すと少し遅れて消える[1]使えない場合がある。パッケージで確認[1]

6. 大きさと重さ

LED 電球は、口金のまわりの形や長さ・外径が白熱電球と違うことがあります。器具のカバーや器具の中に収まるかを確かめます。シャンデリアのように電球をたくさん付ける器具では、電球の総重量にも気をつけます[2][3]。

交換するときの注意

  1. 電源を切ってから取り付け・取り外しをする（感電のおそれ）[1]。
  2. 点灯中や消灯直後は電球が熱いので、冷めてから触る（やけどのおそれ）[1]。
  3. 器具に表示された消費電力（W）以下のランプを使う[1]。
  4. ソケットに確実にねじ込む（落下のおそれ）[1]。
  5. 点けたあと、紙や布で覆ったり、燃えやすいものを近づけたりしない（火災のおそれ）[1]。
電気代はどれくらい変わる？

60W 形の白熱電球（54W）を 7.5W の LED 電球に替えて年 2,000 時間点けると、年に約 2,900 円の差になります（単価 31円/kWh で計算）。自宅の条件での計算はメリット・デメリットのページでできます。
